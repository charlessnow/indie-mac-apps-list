# Indie Mac Apps List

A focused collection of independently developed Mac apps, organized by the work they help you do.

Maintained by [Indie Mac Apps](https://indiemacapps.com/?utm_source=github&utm_medium=referral&utm_campaign=indie_mac_apps_list), an editorial directory for discovering Mac software. This repository is a lightweight reading list; the website provides app details, guides and filters.

## How to use this list

Start with a task, read the short descriptions and follow an app's name to its official website. Check current pricing, system requirements and availability there before installing or buying. Descriptions summarize publicly documented functions; inclusion does not imply hands-on testing or a security audit.

“Independent” refers to the developer or team, not the software license. This list can include paid, free and open-source apps. It is a selected starting point, not an exhaustive catalog or a ranking.

### Planning and notes

- [Things 3](https://culturedcode.com/things/) — Capture tasks, organize projects and plan each day.
- [NotePlan](https://noteplan.co/) — Bring daily notes, tasks and calendar context together for everyday planning.
- [Bear](https://bear.app/) — Write and organize a personal note library with Markdown and tags.
- [Craft](https://www.craft.do/) — Draft documents, arrange ideas and share finished material in a document workspace.

### Desktop utilities and automation

- [Alfred](https://www.alfredapp.com/) — Find apps, files and web searches from a keyboard-driven launcher.
- [Keyboard Maestro](https://www.keyboardmaestro.com/main/) — Turn repeated desktop tasks into reusable macros.
- [Maccy](https://maccy.app/) — Search clipboard history and reuse copied items from a keyboard-focused menu.
- [Rectangle](https://rectangleapp.com/) — Arrange windows using keyboard shortcuts and drag-to-snap actions.
- [Soulver](https://soulver.app/) — Work through calculations in a readable, notepad-style scratchpad.

### Developer tools

- [Nova](https://nova.app/) — Edit source files and work on development projects in a Mac-native editor.
- [TablePlus](https://tableplus.com/) — Connect to and work with multiple database systems in one desktop client.
- [Tower](https://www.git-tower.com/mac) — Review Git working copies, branches and diffs in a visual desktop client.
- [Transmit](https://panic.com/transmit/) — Transfer files between a Mac, remote servers and supported cloud storage.

For a broader selection, browse the [Developer Tools directory](https://indiemacapps.com/categories/developer-tools?utm_source=github&utm_medium=referral&utm_campaign=indie_mac_apps_list).

### Images, screen capture and audio

- [Acorn](https://flyingmeat.com/acorn/) — Edit images using layers, selections, filters and export controls.
- [Audio Hijack](https://rogueamoeba.com/audiohijack/) — Set up repeatable Mac audio-capture sessions.
- [Screen Studio](https://www.screen.studio/) — Record and edit your screen for product demos and tutorials.
- [Shottr](https://shottr.cc/) — Capture and annotate screenshots, measure details and extract text from images.

### Text editing and reading

- [CotEditor](https://coteditor.com/) — Create and edit plain-text files in a focused macOS editor.
- [NetNewsWire](https://netnewswire.com/) — Gather RSS feeds into a reading list and keep track of unread items.

### Network visibility

- [Little Snitch](https://www.obdev.at/products/littlesnitch/index.html) — Inspect application network connections and set rules for handling them.

## How apps are selected

- A current Mac product with an identifiable developer and official website.
- A clear use case that can be described without promotional claims.
- A focus on independent developers and small teams; uncertain ownership needs clarification.
- Descriptions written for this list, with official destinations instead of download mirrors or affiliate links.

Features and ownership can change. Please [report a correction](https://github.com/charlessnow/indie-mac-apps-list/issues/new/choose) if something no longer matches the app's official information. A website listing and a GitHub entry are separate editorial decisions.
