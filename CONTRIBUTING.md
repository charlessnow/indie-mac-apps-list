# Contributing

Help keep this list useful by suggesting an app, correcting a description or reporting an outdated official link.

## Suggest an app

Open an issue using the app suggestion template. Include the app's name, official website, what it does on macOS and a public source identifying its developer. Explain who it helps and what distinguishes it from similar apps.

We focus on independently developed Mac software. Free, paid and open-source apps can all qualify. “Independent” does not mean “open source.” If ownership or current Mac availability is unclear, tell us rather than guessing.

To submit an app for consideration on the website, use the [Indie Mac Apps submission page](https://indiemacapps.com/submit?utm_source=github&utm_medium=referral&utm_campaign=indie_mac_apps_list). A GitHub suggestion does not automatically create or approve a website listing.

## Editorial standards

- Write a short original description about the job the app helps with.
- Link directly to the official app website; do not use shortened, affiliate or download-mirror links.
- Support factual corrections with public sources. Do not claim hands-on testing unless you performed it and explain its scope.
- Disclose if you make, work for or have a commercial relationship with the app.
- Do not copy another list, review, screenshot or proprietary description.
- Inclusion is an editorial choice, not a guarantee of quality, safety or future availability. No reciprocal link or GitHub star is required.

## Documentation only

This repository accepts Markdown resource documents only. Do not submit source code, scripts, GitHub Actions, package files, application configuration, installers, archives, datasets or generated website files. Code embedded in a Markdown file is also outside scope.

Do not post credentials, private correspondence, personal submission information or internal development material in issues, pull requests or attachments. All discussion here is public.

Keep pull requests focused on one suggestion or correction. Maintainers review the description, official destination, relevance and file contents before merging.
